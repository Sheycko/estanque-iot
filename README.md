# Sistema IoT - Estanque Inteligente

## Integrantes

- Benjamin Valdebenito
- Gustavo Fuentes

## Descripción

Este proyecto consiste en un sistema IoT basado en ESP32 que permite monitorear el nivel de agua de un estanque.

El sistema recibe información desde dispositivos ESP32, procesa los datos mediante Python Flask, registra todos los eventos en Supabase y muestra el estado del sistema mediante una interfaz web.

## Tecnologías utilizadas

- ESP32
- Python
- Flask
- Supabase
- HTML
- CSS
- GitHub

## Funciones

- Monitoreo del nivel de agua.
- Registro de eventos.
- Activación de LEDs.
- Monitor en tiempo real.
- Control desde interfaz web.
